怎麼讀這份報告

這份報告只整理「發生了什麼」，不會告訴你「該做什麼」——原因跟怎麼自己判讀，見下面：

  1. 方向是什麼？看 +/− 號，這是唯一的客觀事實，其他都是解讀。
  2. 有沒有「量」佐證「價」？量增價漲代表比較多人同時在買，參與度較高；但也常常是「最後一批追高的人」——兩種解讀都成立，沒有公式能分辨。
  3. 均線位置是「已經發生」，不是「即將發生」。均線是落後指標，看到訊號時，這段走勢往往已經進行一段時間了，這是這類指標天生的限制。
  4. 符合的條件數代表「訊號醒目」，不代表「機率更高」。條件越多只是好幾個角度剛好指向同一件事，統計上不必然更可靠。
  5. 永遠先問：如果判斷錯了，會虧多少？風險控管（部位大小、停損）的重要性，高過判斷方向對不對，這是專業交易者的共識。
